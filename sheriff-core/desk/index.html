A blank block will open in the editor. Add fields as label = value, one per line.

        
Prefix a label with _ to make it a full-width row instead of a two-column row — good for images or section headers:

        
_image = [[image:map.png|full|center|]]
government = monarchy

Seed pages

  
Create several starter articles at once by listing the pages you want under their categories. Each new article is a stub: a real, editable page marked as unfinished.

  
    
    
  1. Write your planUpload a YALL file or edit the example below. Set a directory for each group, then list the pages to create.
    2. 
    
  2. Preview pagesCheck the proposed articles and categories. Existing articles are skipped; conflicts must be resolved.
    3. 
    
  3. Create, then buildCreate pages writes the article files. Find them in Content, then use Build portal to put them on your site.
    4. 
  


  

  
  
  
This example is switched off. Lines starting with # are comments. Remove # from the seed: line and its category, directory, page, and settings lines to activate them. Keep the explanatory lines commented.

  
Save seeder.yall saves only this plan for later. Create pages saves the plan and creates missing articles. Keep the file and add more entries whenever you want; rerunning it leaves existing articles unchanged.
